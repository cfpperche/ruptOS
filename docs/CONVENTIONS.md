# Conventions

## Language

Official project language is **English**. Code identifiers, commit messages, issues, pull requests, and docs in this repository are English. Conversation with the owner may be Portuguese. Artifacts that land here are not.

## Names

| Name | Means |
|---|---|
| ruptOS / Rupture | The product. The computer that is an agent. |
| ruptured | Seat-owning daemon. The body runtime. |
| rupture (user) | The Unix account that owns the graphical session. Not a human persona. |
| tissue | Fedora + kernel + compositor. Not marketed. |
| nerve / reflex | The two body paths. |
| channel | Inbound prompt. |
| wheel | Human temporarily owns input. |

Do not revive Habitat or Corpus as product names in this tree. Those were working titles. If you must refer to them, call them prior sketches.

## Commits

Imperative, specific, English.

```
Add wlr-screencopy path to ruptured
Document nftables as firewall organ
```

Not: `wip`, `ajustes`, `update files`.

## What we refuse in this repo

- Vendor agent CLIs as the runtime
- A human desktop as the default session
- Security theater that blocks Phase A (security is real; it is not the current gate)
- Docs in Portuguese inside `docs/`
- Secrets in git
